# Public workspace tools

This directory is installed verbatim into every submission workspace as
`bin/` (executable wrappers plus this README). Both tools are gold-free and
safe for repair loops (M4) and agent use (M5).

## `validate_submission`

Public, gold-free validation of a candidate submission.

```text
bin/validate_submission --workspace . [--submission submission/] \
    [--out diagnostics.json] [--no-exec] [--quiet]
```

- Runs gates G0–G5 plus G6-Exec (scenario execution on public fixture inputs
  and artifact conformance against the public contract schemas).
- Emits structured JSON diagnostics (`code`, `message`, optional `path`)
  suitable for the M4 repair loop and the M5 agent. `--no-exec` runs the
  structural gates only (cheaper repair iterations).
- Exit code 0 on pass, 1 on fail. `overall_status` and `first_failing_gate`
  are reported; gates whose inputs are missing are `skipped`, never counted
  as failed.
- Never reads gold artifacts, candidate labels, assertions, or review records.
- Never reports assertion outcomes (G6-Assert is evaluation-only).

## `compile`

Deterministic projection of ServiceFlowIR to the executable runtime and Argo
resources.

```text
bin/compile --workspace . [--submission submission/] [--out submission/argo/]
```

- Regenerates `submission/runtime/manifest.yaml` and
  `submission/runtime/scripts/*.py` from `submission/serviceflow.yaml`, public
  contracts, and public fixtures, then projects them to Argo resources.
- `runtime/` and `argo/` are compiler-owned derived outputs; methods must not
  author or repair them directly.
- Exit code 0 on success, 1 on compilation failure (stderr carries the error).
- Same implementation the evaluator re-runs at scoring time (drift check).

## Submission package contract

```text
submission/
  serviceflow.yaml        # sole model-authored source document
  runtime/
    manifest.yaml         # generated by bin/compile
    scripts/*.py          # generated public-contract mocks
  argo/                   # generated by bin/compile
```
