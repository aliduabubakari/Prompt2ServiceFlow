# Reproducing the paper results

## Verify completeness and integrity

```bash
shasum -a 256 -c results/paper/SHA256SUMS
wc -l results/paper/run_index.csv
```

The index has one header plus 7,590 observations. `results/paper/analysis/batch_validation.json` must report 5,940 primary cells, 1,650 ablation cells, 110 instances in each analysis, and zero validation errors.

## Regenerate tables

```bash
make paper-analysis
```

Equivalent direct invocation:

```bash
python3 scripts/prepare_evaluation_final_results.py \
  --primary-batches \
    results/paper/batch_summaries/primary-sintef-v19.json \
    results/paper/batch_summaries/primary-qwen480-v21.json \
    results/paper/batch_summaries/primary-deepseek41-v22.json \
  --ablation-batches \
    results/paper/batch_summaries/ablation-main-v24.json \
    results/paper/batch_summaries/ablation-extension-v24.json \
    results/paper/batch_summaries/ablation-validation-v24.json \
  --posthoc-main-g6 results/paper/analysis/posthoc_main_g6_assert.json \
  --out results/regenerated/evaluation_final
```

Compare regenerated tables with the packaged bundle. CSV rows are compared
semantically so platform-specific line endings do not matter; JSON numbers
use a small tolerance for harmless floating-point serialization differences:

```bash
make verify-analysis
```

## Trace a reported value to a run

1. Select a row in `primary_run_level.csv` or `ablation_run_level.csv`.
2. Open its relative `manifest_path`.
3. Inspect the manifest’s model, method, instance, sample index, usage, evaluation summary, and freeze metadata.
4. Inspect the sibling `score.json` where present; the complete response, submission, validation, and M5 transcript records use the same run ID in the archival release.
5. Verify any file using `results/paper/SHA256SUMS`.

Rendered prompts are regenerated by the method code and are not repeated in the repository. The frozen visible workspace can be rebuilt from the corpus with `scripts/build_submission_workspace.py`. Responses and evaluated artifacts are preserved for the versioned archival release.

## Re-executing the Main G6 assertion audit

The packaged post-hoc audit used no new LLM inference. To rerun it, first rebuild `experiments/workspaces`, then invoke `scripts/rescore_main_semantic_assertions.py` with the three packaged primary summaries and the Main ablation summary. This step executes generated runtime code and should be performed only in the supported local sandbox.
