# Documentation guide

Start with these files for the paper reproduction:

1. `QUICKSTART.md` — install, verify, and run a pilot.
2. `METHODS.md` — M0--M5 and gate applicability.
3. `EXPERIMENT_PROTOCOL.md` — frozen design, repetitions, validity, and analysis.
4. `REPRODUCING_PAPER_RESULTS.md` — regenerate the reported tables.
5. `ADDING_MODELS.md` — evaluate another OpenAI-compatible model.
6. `RESULT_ARTIFACTS.md` — result directory and field guide.
7. `M5_AGENT.md` — sandboxed agent baseline.
8. `TROUBLESHOOTING.md` — common operational failures and safe resume behavior.
9. `RELEASE_CHECKLIST.md` — final checks before public deposit.

The remaining documents describe corpus construction, annotation, schema design, service taxonomy, provider-specific history, and the benchmark release process. They are supporting provenance rather than the shortest route to reproducing the paper tables.
