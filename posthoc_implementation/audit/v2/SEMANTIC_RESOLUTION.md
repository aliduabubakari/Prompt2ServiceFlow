## Reusable correction

`semantic_completion.complete` implements a typed, registered auxiliary-output
completion followed by the existing deterministic assembly policy. It does not
look for an artifact name, pipeline id, model id, hidden filename or expected
value. The public projection contract identifies an implemented publisher
projection by service/version/operation, port cardinality, artifact role/type
and existing producer/output declarations.

Completion requires exactly one existing unused JSON/object report declared by
its producing intent, one existing primary publication, a public artifact/many
output port, and the already implemented audit projection. The report must
have no consumers, input binding or external fixture source. Multiple choices,
unknown operations, wrong types or a consumed report stop completion unchanged.
The rule cannot create a missing business artifact, choose a new service or
source, rewrite control edges or alter parameters. Existing artifact metadata
and existing bindings are preserved; the extra binding and all redundant-list
updates are saved as explicit edits. A publisher computes actual audit contents.

This is a newly declared compiler-elaboration condition informed by this
development failure, not a lossless parser recovery or confirmatory M4 result.
It deliberately expands the old assembly policy to bind a registered auxiliary
projection; do not hide that distinction. Freeze it before any subsequent
measurement and test applicability/ambiguity across other outputs separately.
